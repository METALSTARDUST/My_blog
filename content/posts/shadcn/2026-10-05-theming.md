## A ideia central

O shadcn/ui usa e recomenda **CSS variables** para theming. Isso dá **tokens semânticos** de tema, como `background`, `foreground` e `primary`, que os componentes usam por padrão. Para mudar a aparência do app, você sobrescreve (_override_) esses tokens no seu CSS, sem reescrever as classes dos componentes.

```tsx
<div className="bg-background text-foreground" />
```

Para usar CSS variables, defina `tailwind.cssVariables` como `true` no `components.json`. Esse é o valor padrão. O Tailwind mapeia os tokens para utilities como `bg-background`, `text-foreground`, `border-border` e `ring-ring`.

O **dark mode** funciona sobrescrevendo os mesmos tokens dentro de um seletor `.dark`. A documentação de dark mode mostra como adicionar um theme provider e alternar a classe `.dark`.

## Convenção de tokens

Os tokens vêm em pares semânticos de _background_ e _foreground_ (não confunda com os tokens de inteligência artificial):

- o token base controla a cor da **superfície**;
- o token com sufixo `-foreground` controla a cor do **texto e dos ícones** que ficam em cima dessa superfície.

O sufixo `background` é omitido no token da superfície: `primary` faz par com `primary-foreground`.

```tsx
<div className="bg-primary text-primary-foreground">Hello</div>
```

Aqui o fundo será `var(--primary)` e o texto, `var(--primary-foreground)`.

## Tokens do tema

Ficam no CSS dentro de `:root` e `.dark`.

| Token                                | O que controla                                           | Usado por                                               |
| ------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------- |
| `background` / `foreground`          | Fundo padrão do app e cor do texto                       | Estrutura da página, seções e texto padrão              |
| `card` / `card-foreground`           | Superfícies elevadas e o conteúdo dentro delas           | Card, painéis de dashboard e de settings                |
| `popover` / `popover-foreground`     | Superfícies flutuantes e o conteúdo delas                | Popover, DropdownMenu, ContextMenu e outros overlays    |
| `primary` / `primary-foreground`     | Ações de alta ênfase e superfícies da marca              | Button padrão, estados selecionados, badges             |
| `secondary` / `secondary-foreground` | Ações preenchidas de menor ênfase e superfícies de apoio | Botões e badges secondary, UI de apoio                  |
| `muted` / `muted-foreground`         | Superfícies sutis e conteúdo de menor ênfase             | Descrições, placeholders, empty states, helper text     |
| `accent` / `accent-foreground`       | Superfícies de hover, focus e active                     | Ghost buttons, destaque em menus, linhas com hover      |
| `destructive`                        | Ações destrutivas e ênfase em erro                       | Botões destructive, estados inválidos                   |
| `border`                             | Bordas e separadores padrão                              | Cards, menus, tabelas, separators                       |
| `input`                              | Bordas de form controls e superfície do input            | Input, Textarea, Select                                 |
| `ring`                               | Focus rings e outlines                                   | Botões, inputs, checkboxes e outros controles focáveis  |
| `chart-1` ... `chart-5`              | A paleta padrão de gráficos                              | Charts e blocos de dashboard                            |
| `sidebar` / `sidebar-foreground`     | Superfície base da sidebar e texto padrão                | Container do Sidebar e seu conteúdo                     |
| `sidebar-primary` / `-foreground`    | Ações de alta ênfase dentro da sidebar                   | Itens ativos, ícones, badges e CTAs da sidebar          |
| `sidebar-accent` / `-foreground`     | Estados de hover e seleção dentro da sidebar             | Hover de menu, itens abertos, linhas interativas        |
| `sidebar-border`                     | Bordas e separadores da sidebar                          | Headers, grupos e divisórias internas                   |
| `sidebar-ring`                       | Focus rings da sidebar                                   | Controles com foco dentro da sidebar                    |
| `radius`                             | A escala base do arredondamento de cantos                | Cards, inputs, buttons, popovers e os tokens `radius-*` |

## Escala de radius

`--radius` é o token base de arredondamento do tema. Dele deriva uma escala pequena, para que os componentes usem tamanhos de canto consistentes, com uma _single source of truth_ (fonte única da verdade):

- `radius-lg` é o valor base;
- os radius menores diminuem a partir de `--radius`;
- os maiores aumentam a partir de `--radius`;
- mudar `--radius` atualiza a escala inteira.

## Adicionando novos tokens

Para adicionar um token novo, defina-o em `:root` e `.dark` e exponha-o ao Tailwind com `@theme inline`. Depois disso você já pode usar `bg-warning` e `text-warning-foreground` nos componentes.

## Base colors

`tailwind.baseColor` controla os valores padrão de token gerados quando você roda `init` ou usa um preset. As base colors disponíveis são: Neutral, Stone, Zinc, Mauve, Olive, Mist e Taupe.

A página também traz o **Default Theme CSS**, o scaffold completo do tema neutral padrão, para copiar no CSS global e ajustar.

## Sem CSS variables

Se você não quer usar CSS variables, a CLI pode gerar componentes com Tailwind color utilities direto nas classes (_inline_). Isso define `tailwind.cssVariables` como `false` no `components.json`.

Essa é uma escolha feita na instalação. Para trocar em um projeto existente, é preciso deletar e reinstalar os componentes.

## Dicionário rápido

| Termo      | O que é na prática                                             |
| ---------- | -------------------------------------------------------------- |
| theming    | Aplicar um tema (cores, radius, fontes) no sistema todo        |
| token      | Variável com nome semântico (`primary`) em vez de uma cor fixa |
| semantic   | O nome diz a função (`destructive`), não a cor (red)           |
| override   | Sobrescrever o valor padrão com o seu                          |
| surface    | A "camada" de fundo onde o conteúdo fica (card, popover)       |
| foreground | Cor do que fica em cima da surface (texto, ícone)              |
| muted      | Discreto, de baixa ênfase                                      |
| accent     | Cor de interação (hover, foco, seleção)                        |
| ring       | O contorno que aparece quando um elemento está com foco        |
| preset     | Configuração de tema pronta para reaproveitar                  |
| scaffold   | Estrutura inicial pronta que você ajusta                       |

## Dois pontos de atenção

- Os valores de cor usam **oklch**, um formato de cor mais moderno que hex/rgb.
- `@theme inline` é uma diretiva do **Tailwind v4**. Vale conferir qual versão o projeto usa antes de copiar o CSS.
