## O que são LLMs

**LLM** vem do inglês _Large Language Models_, ou **grandes modelos de linguagem**. São um tipo de inteligência artificial treinado para **entender e gerar linguagem humana**, com base em conjuntos de dados de texto muito grandes.

Eles são a base da maioria das IAs generativas, como o ChatGPT e o Gemini.

## Processo de criação de um LLM

| Dados                        | Processamento                  | Treinamento            | Produção                  |
| ---------------------------- | ------------------------------ | ---------------------- | ------------------------- |
| Grande quantidade            | Tokenização (divisão de texto) | Clusters de computação | Disponibilização para uso |
| Grande diversidade           | Transformadores                | Custo elevado          |                           |
| Texto da web, literatura etc |                                |                        |                           |

1. **Dados:** o modelo parte de uma grande quantidade de texto e de uma grande diversidade de fontes, como texto da web e literatura.
2. **Processamento:** o texto é dividido em partes (**tokenização**) e processado por **transformadores**.
3. **Treinamento:** acontece em clusters de computação e tem custo elevado.
4. **Produção:** o modelo é disponibilizado para uso.
