## O que quero construir

Um diário de desenvolvimento. Não precisa ser uma grande descoberta todos os dias: pode ser um comando útil, um bug resolvido ou uma ideia que merece sair da cabeça.

O objetivo é ter uma referência para o meu eu do futuro — um **save point** para não perder os aprendizados no caminho.

## Como vou registrar cada fase

- **O que fiz:** o projeto ou problema em que trabalhei.
- **O que aprendi:** uma explicação com minhas palavras.
- **Onde travei:** o erro, a investigação e o que funcionou.
- **Próximo passo:** o que ainda quero experimentar.

## Código também faz parte

Os registros podem incluir pequenos exemplos para consultar depois:

```typescript
const jornada = {
  player: "Metal",
  objetivo: "Aprender e construir um pouco a cada dia",
};

console.log(jornada.objetivo);
```

Trocar este exemplo pelo primeiro registro real. Sem a obrigação de saber tudo: só de continuar aprendendo.
