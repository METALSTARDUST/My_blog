# My_blog — Regras do repositório

## README.md (regra obrigatória)

Sempre que editar o `README.md`, preserve as duas imagens de moldura:

1. **No começo** (primeira coisa do arquivo, logo após o comentário de regra): `docs/images/readme-top.jpeg` — a imagem do céu/planeta com o Sonic.
2. **No final** (última coisa do arquivo): `docs/images/readme-bottom.jpeg` — a imagem do Metal Sonic.

Nunca remova, troque de lugar ou inverta essas imagens.

O README também deve sempre manter:

- Uma seção explicando as **referências a Sonic/cultura pop** (o dono é grande fã de Sonic; personagem favorito: **Metal Sonic**) para ninguém estranhar.
- Uma seção avisando que **tudo é feito com ajuda de IA**: o dono só digita (descreve) e revisa o código.
